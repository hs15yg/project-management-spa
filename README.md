# 📌 Project Management SPA

## 📖 Overview

This project is a **Single Page Application (SPA)** built for managing internal company projects.  
It simulates a real corporate system where users can log in and manage projects depending on their role.

The system was developed using **Vanilla JavaScript** and a simulated backend with **JSON Server**, focusing on authentication, role-based access control, CRUD operations, and session persistence.

The main goal of this project is to demonstrate fundamental JavaScript skills without using frameworks like React or Vue.

---

## 🎯 Project Purpose

The application was designed to solve a common company need:

- Manage internal projects
- Assign responsibilities
- Track project status
- Control user permissions

There are two types of users:

- **Manager** → full control over the system  
- **Collaborator** → limited access to assigned tasks

---

## ⚙️ Technologies Used

This project was developed using:

- HTML5 → structure of the application  
- CSS3 → styling and UI design  
- JavaScript (Vanilla) → application logic  
- Fetch API → communication with backend  
- JSON Server → fake REST API  
- LocalStorage → session persistence  

No frameworks or libraries were used to meet academic requirements.
